# Basic sample

Open `DepthDemo.unity` and press Play. The scene shows the input image, depth map
and a displaced mesh.

Assign **Sample Image** for a different photo, enable **Use webcam**, or assign a
prepared `VideoPlayer`. Adjust quality, relief and orbit with the on-screen controls.

The sample uses the Built-in Render Pipeline. `Waterfall.jpg` is the default photo;
`Studio.png` is a landscape alternative. See the package's Third Party Notices for
photo usage terms.
