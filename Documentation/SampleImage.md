# Sample image

## Default: waterfall portrait

`Assets/DepthDemo/Waterfall.jpg` is a real photograph of **Ashkon Khalkhali**, supplied by him as `IMG_0452.JPG` for the demo on October 22, 2026. The repository copy preserves the original 1536×2049 image and JPEG image data. Embedded EXIF/location metadata has been removed; there is no crop, retouching, generative edit or replacement background.

The foreground person and railing, rock walls, bridge and distant waterfall provide several depth layers. Both the Basic and optional BodyPix scenes use this image by default. README previews are captured from the actual Unity depth and mesh outputs, not generated illustrations. The sample preserves portrait proportions in its texture previews, mesh projection and overview capture.

## Alternative: generated studio image

`Assets/DepthDemo/Studio.png` is an original AI-generated fictional photograph, created for this project with the built-in OpenAI image-generation tool on October 22, 2026. No reference photograph was used. It shows a person reaching toward the camera in a studio with several background depth layers, so both depth estimation and optional person segmentation can be demonstrated.

The photograph may be reused with the example without an attribution requirement from this project's contributors. No exclusive copyright claim is made for the generated image. README screenshots are actual Unity output, not generated depth-map illustrations.

### Exact studio generation prompt

Create one photorealistic natural photograph for an open-source monocular depth-estimation software demo. Landscape 3:2 composition, 1536x1024. A fictional adult woman with short curly dark hair in a plain burnt-orange sweatshirt and dark blue trousers stands fully visible in a spacious sunlit industrial art studio, slightly left of center. One arm reaches naturally toward the camera with an open hand, creating clear foreshortening; her other hand rests at her side. Entire body and both feet visible with margin. A simple wooden stool sits farther behind to the right, with a large leafy plant farther back, a concrete floor with strong perspective, tall windows and repeating wooden beams receding into the distance. Natural diffuse daylight, realistic colors and textures, crisp details throughout the scene, moderate wide angle 35mm equivalent, no shallow depth of field, no extreme distortion. Clear separation of person from background for a person segmentation demo and several distinct depth layers. No text, logos, borders, watermark or interface. Single original image, not a montage or depth map.
